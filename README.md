# Insurance Expense Prediction using Machine Learning

## Overview
Built a machine learning regression model to predict individual medical insurance expenses using demographic and lifestyle features.

## Models Used
- Linear Regression
- Ridge Regression
- Lasso Regression
- Random Forest Regressor
- XGBoost Regressor

## Best Result
- XGBoost Regressor
- R² Score: 0.90

## Technologies
Python, NumPy, Pandas, Matplotlib, Scikit-learn, XGBoost, Jupyter Notebook
